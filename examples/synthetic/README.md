# Synthetic ChatGPT export

This ZIP is a hand-authored, fictional example for documentation and importer demonstrations. It contains two invented conversations, one forked message path, and one generated 1×1 placeholder image. It contains no real account data, user archives, share links, or copied conversation text.

The fixture mirrors only the export fields needed to demonstrate this importer. It is not an official complete export schema or a substitute for inspecting a future export version.
